``` markdown

9. 使用 dependency injection 來管理服務。
```

## 系統錯誤收集與分析系統
### 20250307
``` markdown

網站的目的為: 應用系統錯誤收集、彙整與分析

  - 新增錯誤訊息
  - 刪除錯誤訊息
  - 修改錯誤訊息

- 資料存在 in-memory 資料庫，不需要實作登入功能。
```
